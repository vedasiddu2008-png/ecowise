# BUILD A COMPLETE FULL-STACK WEBSITE — SUSTAINABLE LIFESTYLE RECOMMENDATION APP

## 1. PROJECT OVERVIEW

Build a complete, production-ready, responsive web application called:

# 🌱 EcoWise — Sustainable Lifestyle Recommendation App

The goal of the application is to help users make environmentally friendly choices in their everyday lives.

The core problem:

People perform many everyday activities such as travelling, shopping, using electricity, using plastic, wasting water, etc., but they may not know which alternatives are more environmentally friendly.

The application should analyze a user's activity and provide practical sustainable alternatives.

This should NOT be just a static website or UI prototype.

I need a FULLY FUNCTIONAL application where:

* Every button works
* Every form works
* Authentication works
* Supabase database works
* Data persists after refresh
* Analyse functionality works
* Recommendations are generated
* Eco score updates

* Dashboard displays real user data
* History works

# 14. ANALYSIS PROCESS

When user clicks Analyze:

1. Validate input
2. Show loading state
3. Send activity to backend
4. Backend analyzes the text
5. Identify:

   * category
   * activity
   * current choice
   * frequency
   * impact level
6. Generate sustainable recommendations
7. Save activity to Supabase
8. Save recommendations to Supabase
9. Display result
10. Never lose the user's input

If Gemini API is available:

Use Gemini to understand the activity.

Prompt Gemini internally to return structured JSON.

Expected structure:

{
"category": "Transportation",
"activity_name": "Travel to college",
"current_choice": "Car",
"frequency": "Daily",
"impact_level": "Medium",
"analysis": "The activity involves daily individual car travel.",
"recommendations": [
{
"title": "Try cycling",
"description": "Use a bicycle for short-distance travel when practical.",
"difficulty": "Easy",
"points": 20,
"estimated_impact": "Lower environmental impact"
},
{
"title": "Use public transport",
"description": "Use public transportation instead of travelling alone by car.",
"difficulty": "Easy",
"points": 15,
"estimated_impact": "Lower environmental impact"
}
]
}

IMPORTANT:

If Gemini API is unavailable, the Analyze feature MUST STILL WORK.

Implement a deterministic fallback recommendation engine using category keywords.

Examples:

"car", "bike", "bus", "travel", "college", "drive"
→ Transportation

→ Food

This guarantees the application works even without an AI API key.
